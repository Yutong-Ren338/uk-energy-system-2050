UK Energy Modelling with CO2 Removal

A Python-based energy system model for simulating the UK's 2050 net-zero energy landscape.

UCL Department of Physics & Astronomy — High Energy Physics group

About the model

This model simulates the UK's future energy system using hourly and daily time series data, combining renewable generation, demand projections, storage, and carbon dioxide removal into a single simulation framework. It is designed to explore how different technology mixes and policy assumptions could meet UK electricity demand on the path to net zero.

  • Renewable generation from wind and solar, using realistic ERA5-based capacity factors
  • Multiple demand scenarios: naive scaling, seasonal profiles, and CCC Seventh Carbon Budget projections
  • Energy storage with configurable capacity, power and efficiency, including a hydrogen storage pathway
  • Direct Air Capture (DAC) integration for CO2 removal using excess capacity
  • Scenario costing: system cost and energy cost calculations for modelled pathways

Running the model

The full model runs locally as a Python package driven from Jupyter notebooks. Set up the environment with uv: 

uv venv
# Windows:  .venv\Scripts\Activate.ps1
# macOS/Linux:  source .venv/bin/activate

uv sync
uv run pytest   # sanity check

From there, the model is explored through notebooks in nbs/ (e.g. UK Energy Model Final.ipynb), which import the core src/ package. To run the interactive teaching app locally instead: 

uv run streamlit run teaching_site/app.py

Full setup and documentation are in the GitHub repository README.
